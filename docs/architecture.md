# WebDev CRM architecture

Flask application factory, SQLite/SQLAlchemy, Jinja server-rendered pages, vanilla JS enhancements. All blueprints require authenticated administrator access (single administrator initially); future users have role and active flags. Business dates are UTC; UI timezone defaults to Asia/Manila. Money uses Decimal/Numeric, never floating point calculations. No automatic deployment. SMTP defaults to test mode.

## Internal integration contract

- `app.extensions`: `db`, `login_manager`, `csrf`, `migrate`, `limiter`.
- `app.models.base`: `BaseModel` abstract with integer id, created_at, updated_at and `utcnow()` naive UTC for SQLite; `money(value)` quantizes Decimal.
- All models exported from `app.models`. Core model file: `core.py`; other owners: `finance.py`, `communications.py`, `delivery.py`.
- Core: User(email,name,password_hash,role,active,set_password/check_password); Lead(reference,name,business_name,email,phone,website,industry,location,source,service,budget,desired_date,notes,status,follow_up_at,last_contacted_at,client_id); Client(reference,name,business_name,email,phone,website,industry,location,notes,status,lead_id); Contact(client_id,name,email,phone,role); Inquiry(reference,lead_id,client_id,project_id,website_type,business_description,features,budget,desired_date,communication,answers JSON,notes,status); Project(reference,client_id,title,description,status,current_stage int default 1,contract_value Numeric,currency,deadline,revision_allowance int,repository_url,staging_url); ProjectStage(project_id,number,title,status,data JSON,completed_at); StageTransition(project_id,from_stage,to_stage,reason,actor_id); Requirement(project_id,stage_number,title,required bool,completed bool,exception TEXT); ScopeItem(project_id,name,description,hours Numeric,rate Numeric,complexity,priority,dependencies TEXT,acceptance_criteria,included bool,status); ProjectMilestone(project_id,title,due_at,completed bool); Task(project_id nullable,client_id nullable,stage_number nullable,title,description,status,priority,due_at,estimated_hours Numeric,actual_hours Numeric,assigned_user_id,completed_at,event_key unique nullable); TaskDependency(task_id,depends_on_id unique pair); Approval(project_id,stage_number,kind,decision,person,evidence,actor_id) immutable records; ActivityLog(client_id nullable,project_id nullable,action,description); AuditLog(actor_id,action,entity,entity_id,details); ApplicationSetting(key unique,value TEXT); Notification(title,body,read bool,project_id nullable).
- `app.services.common`: `log_activity(action, description, client_id=None, project_id=None)`, `audit(action,entity,entity_id,details='')`, `setting(key,default='')`. These add session objects WITHOUT commit. `admin_required` decorator.
- `app.services.lifecycle_service`: `create_project(client,title,description='')` adds project+14 stages+checklists WITHOUT commit; `complete_stage(project,number,actor_id=None)` validates and commits transition only via caller; `transition(project,target,reason,actor_id=None)` supports deliberate backward movement.
- Flask blueprints: `auth`, `crm`, `finance`, `communications`, `delivery`, `dashboard`. Unique names/endpoints. App factory imports and registers each `bp` from matching file under `app.blueprints`.
- UI templates: `base.html` with blocks `title`, `content`, `scripts`; `list.html` accepts title, subtitle, columns [(attribute,label)], rows, new_url optional, detail_url optional callable, filters optional, actions optional; `form.html` accepts title, fields [dict(name,label,type,required,options [(value,label)],value)], submit_label; `detail.html` accepts title, subtitle, record, sections, actions; module owners may supply own specialized templates. All forms include CSRF via `csrf_token()`.
- All generic POST routes accept normal request.form (HTML) and JSON where explicitly documented. Handle ValueError/IntegrityError with rollback, flash, status 400. Never swallow errors. JSON errors return {error: message}; data responses use {ok: true,...}. CSRF required on mutations.
- Core routes owner root: CRM clients/leads/inquiries/projects, lifecycle/scope/tasks/approvals. Foundation owner auth, config, common, CLI. Finance owner /proposals /contracts /invoices /payments /expenses and financial service. Communications owner /email /documents /settings/automations and scheduler. Delivery owner project /design /testing /launch /handover, /maintenance /support and corresponding data. UI owner dashboard /calendar /analytics /settings /search and all shared layout/static.
- Every route references a real URL with working forms. Module-specific templates owned by module implementer; shared base/list/form/detail owned UI agent.
- Tests use pytest factory `create_app({'TESTING':True,'SQLALCHEMY_DATABASE_URI':'sqlite://','WTF_CSRF_ENABLED':False,'SECRET_KEY':'test'})`, `db.create_all()`. Tests should mock SMTP. Production schema uses Flask-Migrate revisions.
- URLs have no trailing slash (use route('') within prefixed blueprints or absolute routes). Fetch JSON mutations require `X-CSRFToken`.
- Settings and demo command must never seed real credentials or default passwords. `flask --app run:create_app create-admin` prompts securely or uses env `ADMIN_PASSWORD` (never persisted in source). `seed-demo` only when APP_ENV=development and sets demo banner.
